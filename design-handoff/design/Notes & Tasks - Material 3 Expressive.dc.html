1a

Keepsake — notes & tasks

An Android app built on Material 3 Expressive: a green-seeded dynamic color scheme, the 15 + 15 style type scale with emphasized weights, the six-step shape scale with morphing on press, spring-based motion, and the expressive component set (floating navigation bar, FAB menu, docked search, split button, floating toolbar).

Design system → 10 screens · light and dark scheme · 412 × 892 dp

Type scale — Roboto Flex
Five roles × three sizes, each with an emphasized twin. Emphasized styles carry the same metrics at a heavier weight and are used only for the moments that should sing.
Display Small36 / 44 · w400 · 0
Headline Large32 / 40 · w400 · 0
Headline Medium · emphasized28 / 36 · w500 · 0

Title Medium — note titles16 / 24 · w500 · +0.15
Body Large — note body copy16 / 24 · w400 · +0.5
Body Medium — snippets, supporting text14 / 20 · w400 · +0.25
Label Large — buttons, chips14 / 20 · w500 · +0.1
Label Medium — nav bar, metadata12 / 16 · w500 · +0.5
Emphasized twins in use: Headline Medium 500 for large top app bar titles, Title Medium 700 for the active day header in Tasks, Label Large 700 for the primary action inside a dialog. Never two emphasized styles in one view.
Shape scale & morphing
Corner tokens from extra-small to full. Fully rounded corners use the full token rather than 50% of the component, so shapes stay stable as components resize.

Shape morph on state change. Checking off a task morphs its check target from circle to squircle; pressing a button squares its corners one step and springs back on release.
Motion — physics, not durations
The app themes MotionScheme.expressive(). Springs replace duration + easing pairs; spatial springs may overshoot, effects springs never do.

Effects — color, opacity

Ripple, chip selection, checkbox fill, scrim fade.
Opening a note — container transform from the tapped card into the editor canvas, spatial default; the card's shadow and radius interpolate with it.
FAB menu — items stagger out on spatial fast, 20 ms apart, the FAB icon rotating add → close.
Completing a task — check morph on spatial fast, strike-through on effects default, row settles into Completed with a springy shift of its neighbours.
Tab switch — shared x-axis between Notes, Tasks, Collections; the active indicator travels ahead of the content.
Components in use
Expressive members of the library, mapped to where they appear.
Floating navigation barThree destinations in a 64 dp pill inset 16 dp from the edges, elevation 3, content scrolling beneath it. Only the active destination shows its label, inside a secondaryContainer pill that slides on a spatial-default spring; the inactive two are 48 dp icon targets.
FAB menuMedium FAB expanding into three labelled actions: note, list, reminder.
Docked search barTop of the list, becomes a full-screen search view with recent queries.
Floating toolbarFormatting actions in the note editor, floating above the keyboard.
Split buttonSave + overflow in the task sheet.
Button groupsPriority selection; the pressed member widens and its neighbours give way.
Cards, chips, sheetsFilled cards for items, filter chips for scope, bottom sheet for task editing and label assignment.
Loading indicatorThe expressive shape-morphing indicator for sync, shown in the pull-to-refresh state.

Layout, elevation, accessibility
Compact window class (412 dp). Everything sits on a 4 dp grid with 16 dp body margins and an 8 dp gutter between cards.
lvl 0
lvl 1
lvl 2
lvl 3
Elevation is mostly tonal. Cards sit on surfaceContainerLow with no shadow; only the FAB (lvl 3), floating toolbar (lvl 3), menus (lvl 2) and sheets (lvl 1) cast one.
Touch targets. 48 × 48 dp minimum for every icon button, checkbox and list row; nav bar items 64 dp tall; FAB 56 dp with a 16 dp margin.
Contrast. Body text 8.3:1 or better, labels on containers 7:1+, disabled states use 38% onSurface. Status is never carried by color alone — overdue also reads as a word.
Text scaling. Cards grow vertically; snippets clamp by line count, not by height, so 200% font scale never clips a word.
Dynamic color. The green scheme is the fallback brand theme; when the user has wallpaper theming on, all roles come from the system palette and the app changes nothing else.
